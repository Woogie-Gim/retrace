# Retrace v1.0.0

증상만 알려진 간헐 결함의 **최소 재현 스텝을 자동으로 찾아내는** 웹 QA 도구의 첫 정식 릴리스입니다.
찾아낸 재현 스텝은 그대로 실행 가능한 BDD 회귀 테스트가 됩니다.

---

## 주요 기능

| 기능 | 설명 |
|---|---|
| 교란 탐색 | 시드 시나리오 스텝 사이에 연타 / 뒤로가기 / 새로고침 / 네트워크 지연 / 창 크기 / 경계값 입력을 삽입해 증상 재현 |
| 다중 오라클 | 화면 검증 + 콘솔 에러 + HTTP 상태 + API 데이터 대조 |
| 최소화 | Delta Debugging(ddmin)으로 재현 시퀀스의 불필요 스텝 제거 |
| 재현율 측정 | N회 반복 실행 → `확정` / `간헐` / `희귀` 등급 |
| 원인 계층 분류 | 화면 값과 API 값 대조로 FE / BE 결함 자동 구분 |
| BDD 출력 | 최소 재현 스텝을 `.feature`로 출력 → pytest-bdd 회귀 테스트로 실행 |
| 리포트 | 스텝 타임라인 + 스텝별 스크린샷 + 로그, feature 복사 |
| 대시보드 | 시나리오 선택 → 실시간 진행 스트림 → 리포트 → 히스토리 |
| 데모 쇼핑몰 내장 | 버그 4종을 심은 데모 쇼핑몰이 앱과 함께 자동 기동 · 종료 |

## 설치 방법

### 요구 사항
- Windows 10 / 11 (x64)
- Google Chrome 설치
- 첫 실행 시 인터넷 연결 (Chrome 버전에 맞는 chromedriver 자동 다운로드)
- 로컬 포트 `5100`(데모 쇼핑몰) · `5200`(엔진) 사용 가능
- Python 설치 불필요

### 설치본 : `Retrace-Setup-1.0.0.exe`
1. 실행 후 설치 경로 선택 (기본 : 사용자 폴더, 관리자 권한 불필요)
2. 시작 메뉴 또는 바탕화면의 **Retrace** 실행
3. 제거 : Windows 설정 → 앱 → Retrace 제거

### 포터블 : `Retrace-1.0.0-win-x64.zip`
1. 원하는 폴더에 압축 해제
2. `Retrace.exe` 실행

### 데이터 위치
- 리포트 : `%APPDATA%\Retrace\reports` (설치본 · 포터블 공통, 앱 제거 후에도 유지)
- 포트 변경 : `ENGINE_PORT` · `DEMO_SHOP_PORT` 환경변수

## SmartScreen 경고가 뜨는 경우

코드 서명 인증서가 적용되지 않은 빌드라 첫 실행 시 **"Windows의 PC 보호"** 창이 표시될 수 있습니다.

1. 창의 **추가 정보** 클릭
2. 하단에 나타나는 **실행** 클릭

## 알려진 이슈

- **강제 종료 시 demo-shop 잔존** : 작업 관리자의 "작업 끝내기" 등으로 Retrace를 강제 종료하면 `demo-shop.exe`가 남을 수 있습니다. 다음 실행 때 남은 프로세스를 그대로 재사용하므로 기능에는 영향이 없습니다. 정리하려면 작업 관리자에서 `demo-shop.exe`를 종료하세요. 창을 닫는 정상 종료에서는 발생하지 않습니다.
- **포트 점유** : `5200` 포트를 다른 프로그램이 사용 중이면 "포트 5200 이미 사용 중" 화면이 표시됩니다. 해당 프로그램을 종료하거나 `ENGINE_PORT`를 변경하세요.
- 앱 아이콘은 Electron 기본 아이콘입니다.

### 확인 항목
- 설치 → 실행 → 제거, 포터블 zip 실행
- 시드 시나리오 실행 → 최소화 → 검증 → 리포트 · 스크린샷 확인
- PATH에서 Python을 제외한 상태로 실행
- 빈 Selenium 캐시에서 chromedriver 자동 다운로드
- 포트 점유 시 에러 화면 표시
- 실행 도중 창 닫기 → 엔진 · demo-shop · chromedriver · Chrome 프로세스 잔존 없음

### 미확인
- Python · Chrome 드라이버가 전혀 없는 실제 클린 PC
